ℹ️ Tentang AVL Tree

📚 Definisi AVL Tree

AVL Tree (Adelson-Velsky and Landis Tree) adalah sebuah self-balancing Binary Search Tree (BST). Setiap node dalam AVL Tree memiliki balance factor yang didefinisikan sebagai tinggi_subtree_kiri - tinggi_subtree_kanan. Dalam AVL Tree, balance factor setiap node harus bernilai -1, 0, atau 1.

⚖️ Operasi Balancing

Ketika sebuah operasi insert atau delete menyebabkan balance factor melebihi range [-1, 1], pohon harus di-rebalance menggunakan rotasi. Ada empat jenis rotasi:

  • Left Rotation: Ketika tree berat ke kanan (balance factor > 1)
  • Right Rotation: Ketika tree berat ke kiri (balance factor < -1)
  • Left-Right Rotation: Kombinasi rotasi untuk kasus tertentu
  • Right-Left Rotation: Kombinasi rotasi untuk kasus tertentu

🎯 Tingkat Kompleksitas

Operasi Time Complexity Space Complexity
Search O(log n) O(1)
Insert O(log n) O(log n)
Delete O(log n) O(log n)
Traversal O(n) O(log n)

✨ Keuntungan AVL Tree

  • Menjamin operasi insert, search, delete dalam waktu O(log n)
  • Pohon selalu seimbang sehingga mencegah performa worst-case
  • Cocok untuk aplikasi yang membutuhkan banyak operasi pencarian

⏰ Kekurangan AVL Tree

  • Memerlukan informasi balance factor di setiap node
  • Rotasi dapat mahal secara komputasional selama operasi update
  • Lebih kompleks diimplementasikan dibanding BST biasa
